# Stand-for-Amalgamod
This is a simple design to bring Amalgamod cases off the surface while adjusting for angle to keep it from folding in on itself which would be the case with only adding simple feet.

Make sure to use a high quality and precise 3D printer as the opening for the installation slots is quite thin.
Stands can be kept in place when inserting the case into the carrying bag. 
Stands can rotate after you put the case in the bag to press perfectly snug against the top of the cover
Install using simple hook and loop cable ties
